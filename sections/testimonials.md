# Testimonials

The **Testimonials Section** allows you to showcase customer reviews, feedback, or endorsements, building trust and credibility with potential buyers.

{% hint style="success" %}
1. **Go to** Shopify Admin > **Online Store > Themes**.
2. Click **Customize** on your active theme.
3. In the Theme Editor, click **Add Section > Testimonials**.
{% endhint %}

### **Settings & Customization**

<figure><img src="../.gitbook/assets/testimonial-02.jpg" alt=""><figcaption></figcaption></figure>

#### **Layout** <a href="#layout" id="layout"></a>

* **Expand to Full Width:** Enable this option to extend the section across the entire screen width.
* **Color scheme:** You can customize the section’s appearance by changing the **text color, background color**, and more using **preset color** options.
* **Background Opacity:** Set the transparency level (Range: **0–100**, Default: **100**). This applies to the background image, which can be customized in the theme settings.

#### **Content Settings**

* **Heading:** Set a custom title (e.g., _"_&#x57;e’re are featured b&#x79;_"_).
* **Heading Size:** Choose from **Small, Medium, or Large** (Default: **Large**).
* **Text:** Add optional supporting text.
* **Text Position:**
  * **Above Main Heading** – Position the text above the heading.
  * **Below Main Heading** – Position the text below the heading (Default).
* **Desktop Content Alignment:** Choose from **Left, Right, or Center** (Automatically centered on mobile screens).

#### Testimonial settings

* **Block color scheme :** You can customize the section’s appearance by changing the **text color, background color**, and more using **preset color** options.
* **Block text alignment :** Choose from **Left, Right, or Center** (Automatically centered on mobile screens).
* **Desktop Content Separation** – You can **Enable** or **Disable** this option. _(Works only if the product image is used in the block.)_

#### **Column Settings**

* **Desktop Columns** – Choose the number of columns for desktop view. _(Options: 2 or 3)_
* The column option is automatically optimized to a single column on mobile screens.

#### **Carousel Settings** <a href="#carousel-settings" id="carousel-settings"></a>

* **Enable Carousel**: Toggle to display content in a sliding format.
* **Change Slides Every**: Set slide transition delay (in seconds). 0 disables auto-play.
* **Gap**: Defines space between slides (Default: 30). Adjusts automatically on mobile screens.
* **Pagination**: Choose navigation type – Dots (indicators), Arrow (manual navigation), or None.
* **Pagination Style**: Select Classic (traditional) or Modern (contemporary).

#### Section padding <a href="#section-padding" id="section-padding"></a>

* **Top & Bottom Padding:** Adjust the spacing above and below the section for a well-structured layout.

#### **Shapes** <a href="#shapes" id="shapes"></a>

* **Shaper** – Adds shape effects to the section. Options: **Shaper Top, Shaper Bottom, Shaper Both, None, Border Top, Border Bottom, and Both Borders**.
* **Shaper Top Color** – Sets the top shape color (_choose your preferred color_).
* **Shaper Bottom Color** – Sets the bottom shape color (_choose your preferred color_).

### **Testimonial Settings**

* **Quotes Heading**: Enter the testimonial content (e.g., "Best Thrift Store Ever").
* **Heading Size**: Choose from Standard, Minimal, or Big.
* **Text**: Add a short description (e.g., "Use this text to share the information which you like!").
* **Author Avatar**: Upload an image (**100x100px required**).
* **Author Name**: Enter the author’s name (e.g., "Dominic Gibson").
* **Author Details**: Specify the author’s role or profession (e.g., "Artist").
* **Rating**: Specify the author’s review (e.g., 5 ⭐⭐⭐⭐⭐).
* **Product Image**: Upload an image (**500x500px required**).
