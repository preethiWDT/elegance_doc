# Header

The **Header Section** allows you to customize the top section of your store, including navigation, branding, and search functionality. It provides a structured layout to enhance user experience and accessibility.

{% hint style="success" %}
1. **Go to** Shopify Admin > Online Store > Themes.
2. **Click** **Customize** on your active theme.
3. **In the Theme Editor, click** **Header** to access customization settings.
{% endhint %}

### Settings & Customization

<figure><img src="../.gitbook/assets/header-02 (1).jpg" alt=""><figcaption></figcaption></figure>

**General**

* **Color scheme:** You can customize the section’s appearance by changing the **text color, background color**, and more using **preset color** options.
* **Heading**: Add a heading that appears **only on the homepage**.\
  \&#xNAN;_Example: “Canvas creations bring walls to life”_

**Header Layout**

* **Enable Circular Header**: Activates a circular layout style for the header.\
  \&#xNAN;_Note: This feature will not show if the heading is left empty._
* **Sticky Header**: Enable or disable the **Sticky** header option..
* **Show Search**: Enable a search icon in the header to help users find products easily.

**Transparent header**

* **Transparent Header**: Activate a transparent background for the header.\
  \&#xNAN;_Note: This only works when the circular header is disabled and the heading is empty._
* **Transparent Header Logo**: Upload a custom logo that will be used only when the transparent header is enabled.
* **Color scheme:** You can customize the section’s appearance by changing the **text color, background color**, and more using **preset color** options.

**Separator Layout**

* **Hide Separator on Homepage**: Remove visual separators from the homepage header.
* **Separator Style**: Choose how the separator appears in the header:
  * **Artistic**: Creative, stylized separator
  * **Line**: Minimal line-based separator

**Navigation**

* **Main Menu**: Select the primary menu to display in the header. (_Example: Main menu)_
* **Show Menu Items as Icons**: Toggle to show menu links with icons.
* **Desktop Menu Type**: Choose the menu format for desktop view:
  * **Drawer**: Side-panel navigation
  * **Megamenu**: Expanded dropdown with multi-column layout
* **Menu Color Scheme**: You can customize the section’s appearance by changing the **text color, background color**, and more using **preset color** options. This will apply to the **mobile menu**, **mega menu**, and **menu drawer**.
* **Logo Position**: Choose where the logo appears in the header – **Left** or **Middle**.\
  \&#xNAN;_Upload your logo under Theme Settings > Logo._

**Theme Settings**

* **Separator Style**: Choose how separators appear in offcanvas areas such as mobile or drawer menus.
  * **Artistic**: Decorative visual separator
  * **Line**: Simple, clean line-based separator
* **Logo**: Upload your main store logo.
* **Search Style :** Choose how the search interface appears on your store:
  * **Drawer** – Opens as a sliding side panel
  * **Page** – Redirects users to a dedicated search results page
* **Cart Type :** Choose how the cart appears when accessed by users:
  * **Popup** – Displays as a centered overlay window
  * **Drawer** – Opens from the side as a sliding panel
  * **Page** – Redirects users to a full cart page
* **Cart Icon :** Select the visual icon style for the cart in your store's header:
  * **Bag** – Shopping bag icon
  * **Cart** – Traditional shopping cart icon
  * **Basket** – Basket-style icon
* **Custom CSS**: Add your own CSS rules to further customize the appearance and functionality of the header.
